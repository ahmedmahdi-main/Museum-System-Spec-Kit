# UI Workflow Contracts

هذه العقود تصف سلوك الواجهة العربية RTL المتوقع لموظفي المخزن والسجل والجرد. الهدف تقليل الخطوات مع الحفاظ على قواعد السلامة.

## Common UI Rules

- كل الشاشات عربية RTL.
- المصطلحات الموحدة: الرقم المتحفي، الحالة الحالية، الجهة الحالية، موقع الخزن الحالي، آخر موقع خزن.
- رسائل الخطأ قصيرة وقابلة للتصرف.
- لا تعرض الواجهة تفاصيل تقنية مثل أسماء الجداول أو stack traces.
- العمليات الحساسة تعرض مراجعة مختصرة قبل الحفظ.

## Artifact Search

**Entry points**:
- شريط بحث رئيسي في واجهة الموظف.
- فلاتر اختيارية للحالة والموقع والجهة.

**Result row must show**:
- الرقم المتحفي.
- وصف مختصر.
- الحالة الحالية.
- الموقع الحالي أو الجهة الحالية.
- آخر موقع خزن معروف.

**Empty state**:
- رسالة: لا توجد قطع مطابقة.
- لا تنشئ الواجهة سجلاً جديداً تلقائياً من البحث.

## Create Artifact

**Steps**:
1. اختيار الفئة وإدخال رقم القطعة والوصف الأساسي.
2. اختيار موقع الخزن الأولي.
3. حفظ.

**Blocking errors**:
- الرقم مستخدم داخل الفئة.
- الفئة غير نشطة.
- الموقع غير صالح.

## Delivery

**Steps**:
1. اختيار قطعة أو مجموعة من البحث/القائمة.
2. إدخال الجهة المستلمة واسم المستلم والغرض وملاحظة اختيارية.
3. مراجعة مختصرة وحفظ.

**Bulk behavior**:
- إذا وجدت قطعة غير مؤهلة، ترفض العملية كاملة.
- تعرض الواجهة قائمة القطع غير المؤهلة وسبب كل رفض.
- تحتفظ الواجهة بالمدخلات العامة حتى لا يعيد الموظف إدخال الجهة والغرض.

**Success state**:
- عرض رقم حركة أو ملخص حفظ.
- تحديث الحالة إلى خارج المخزن.

## Return

**Steps**:
1. اختيار قطعة أو مجموعة خارج المخزن.
2. اختيار موقع الخزن وملاحظة اختيارية.
3. مراجعة مختصرة وحفظ.

**Blocking errors**:
- قطعة داخل المخزن أصلاً.
- موقع خزن غير نشط أو غير معروف.
- تغيرت حالة قطعة أثناء العملية.

## Excel Import

**Steps**:
1. رفع ملف Excel.
2. عرض Preview للسجلات المقروءة.
3. تشغيل Validation وعرض الأخطاء والتعارضات.
4. اعتماد صريح للسجلات المقبولة.

**Preview rules**:
- لا تغير أي بيانات مركزية.
- تعرض عدد الصفوف المقروءة وأي أعمدة غير معروفة.

**Validation rules**:
- تعرض الأخطاء على مستوى الصف.
- تسمح بالتصفية حسب Accepted, Rejected, NeedsReview.

**Commit rules**:
- زر الاعتماد لا يتاح إلا بعد validation.
- يوضح الاعتماد عدد السجلات التي ستنشأ أو تربط.

## Reconciliation

**Steps**:
1. اختيار موقع الجرد.
2. إدخال أو تحميل قائمة الأرقام المرصودة.
3. عرض تقرير المطابقة.
4. فتح تصحيح موثق للتعارض المؤكد عند الحاجة.

**Correction rules**:
- السبب مطلوب.
- التصحيح منفصل عن الحركة.
- تظهر إشارة في تفاصيل القطعة أن هناك تصحيحاً موثقاً.

## Audit View

**Visible to authorized users only**:
- المستخدم.
- التاريخ والوقت.
- العملية.
- الكيان المتأثر.
- ملخص التغيير.

**Filtering**:
- حسب القطعة، المستخدم، نوع العملية، المدة الزمنية.
